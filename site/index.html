How it works

  1. Plug the ESP32 into this computer with a USB data cable.
  2. Click Connect & install and pick the device's serial port.
  3. When asked whether to erase the device:
    • Don't erase keeps your saved Wi-Fi network and Bluetooth phone pairing.
    • Erase gives a clean start. Afterwards, join the REMOTEHEAD Wi-Fi network and set it up again at http://192.168.4.1.
  4. Wait for the install to finish (about a minute). The device restarts on its own.

This installs the bootloader, partition table, firmware and web interface, so it also works for devices running older releases.

Already set up? Update over Wi-Fi

Devices running a release with Wi-Fi update support can be updated without a cable:

  1. Download remotehead.bin from the latest release.
  2. Open the device's own web page (its IP address on your network).
  3. Under Firmware Update, choose the file and press Upload and Install.

A Wi-Fi update replaces the firmware but not the web interface. If a release changes the web interface, install it from this page over USB instead.

Trouble connecting?

  • No serial port listed? Try another cable, since some are power-only. You may also need the CP210x or CH340 USB driver.
  • Stuck on "Connecting"? Hold the BOOT button on the board while the install starts.
  • Close any other program using the port, such as a serial monitor.
